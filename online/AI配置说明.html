接入大模型 API / 反代

  1. 将同目录的 .dev.vars.example 复制为 .dev.vars。
  2. 填写 AI_BASE_URL（服务地址，含 /v1）、AI_MODEL（模型名）、AI_API_KEY（密钥）。
  3. 关闭原启动窗口，重新运行“启动开发.bat”。
  4. 房间开局前选择“API / 反代”。

配置必须是兼容 Chat Completions 的 API 地址。密钥只保存在本机，不要上传 GitHub 或发到聊天中。接口可能产生费用，AI的可见牌桌会发送到你配置的服务。

没有配置或接口失败，自动回退本地AI，不会卡住守夜。
